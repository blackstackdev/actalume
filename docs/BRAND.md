# Actalume identity

## Approved hierarchy

- Product: **Actalume**
- Pronunciation: **AK-tuh-loom**
- Primary line: **Every action leaves a record.**
- Category: **The human-governed system of record for agent work.**
- Technical descriptor: **The evidence layer for agentic work.**

`Acta` evokes recorded acts and proceedings. `Lume` evokes visibility. The intended meaning is **Recorded actions brought into view.**

## Visual system

- Near-black charcoal (`#050706` to `#101513`) is the dominant evidence-ledger canvas.
- Warm bone (`#F2EEE5`) provides primary text and recorded-artifact contrast.
- Amber (`#F5A524`) means an action or evidence has been brought into view.
- Green (`#55A978`) is reserved for work already verified by a human.
- Rust (`#E36F50`) is limited to rejection or prohibition.
- The signature mark is an illuminated A above ledger lines with a narrow amber evidence beam. It carries the dramatic brand moment while the working ledger remains restrained.
- Space Grotesk is the locally bundled product/display face; IBM Plex Mono is the locally bundled custody-data face. The browser makes no runtime font request.

## Product-language rule

Use **Actalume** as the product name. Use **Agent Work Ledger** as a plain-language description where clarity helps. Do not describe Actalume as a generic dashboard or imply unchecked autonomous operation.

The supplied references remain visual direction. The implemented mark is a new generated local PNG asset saved at `public/actalume-mark-illuminated.png`; the selected interface target is recorded at `docs/design/actalume-dark-ledger-target.png`.
